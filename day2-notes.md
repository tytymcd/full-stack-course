# Day 2

## Summary

The topics covered on day 2 of the course are related to Git and Github. Important things to understand are:
- Working Directory: This is the directory (or folder) where I am actively making changes on my own device.
- Staging Area: This is where we can control specific files we want to commit. Often "git add ." is used to just add all files from the working directory, but we can specify files if we only want to commit certain changes.
- Commit: This is how we make a change to the codebase. A commit is a snapshot of what all of our code is at a point in time. This is an important part of change management as we can always find what differences happened between two points in time in our codebase.
- Branch: A branch is an offshoot of our main codebase. It lets us work on the codebase in a dedicated space that will not impact the current main codebase. It's often used for small features rather than major overhauls.
